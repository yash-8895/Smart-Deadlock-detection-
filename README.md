# Smart Deadlock Detection and Resource Management System

## Project Overview

The **Smart Deadlock Detection and Resource Management System** is a Python-based application designed to detect deadlocks, prevent unsafe resource allocation, and manage system resources efficiently.

The project uses Operating System concepts, database management, and machine learning to monitor processes, manage resource allocation, and identify potentially unsafe situations.

## Key Features

- **Deadlock Detection:** Identifies deadlock situations between processes and resources.
- **Deadlock Avoidance:** Implements the Banker's Algorithm to check whether resource allocation keeps the system in a safe state.
- **Resource Management:** Manages available resources, allocated resources, and process requirements.
- **Deadlock Recovery:** Provides recovery mechanisms to handle detected deadlock situations.
- **Database Management:** Stores and manages process, resource, allocation, and system activity records.
- **ML-Based Prediction:** Uses machine learning to predict potentially unsafe resource requests.

## Technologies Used

- Python
- Flask
- SQLite
- MySQL
- HTML, CSS, JavaScript
- Machine Learning (Random Forest)
- Operating System Algorithms

## Objective

The main objective of this project is to demonstrate how deadlocks can be detected and avoided through intelligent resource management, while combining Operating System concepts, database management, and machine learning in a single application.
